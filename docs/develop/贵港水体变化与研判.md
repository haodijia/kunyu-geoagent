## 产品操作

地图右上角“分析与核查”分研究区、核查、研判三页。研究区支持矩形、多边形和WGS84 GeoJSON Polygon/MultiPolygon导入。绘制边界未保存时有提示，地图相机不改变计算范围。保存递增版本并检查旧版本，研判冻结当时的研究区和输入。

核查选定成果后可点击查询原始GeoTIFF数值，对保存研究区、绘制区域或选中候选图斑统计；不从截图或颜色推算。卷帘同步两个图层的相机，结束恢复原显示，地图截图包含卷帘组合。

研判选择同网格的四份单波段成果：前／后期MNDWI、前／后期SCL。填写日期、阈值、校准说明、方法状态、最小图斑及事件背景；探索参数须声明未经独立校准。完成后可下载材料并上图核查候选。成果卡提供离散图例和研判材料。

## 计算与成果

核心指数继续通过`oge_execute_code`在OGE计算，每次导出一个Coverage。`assessment_create`只处理已保存的数值成果，不替代远端计算，不增加第二个Agent循环。

共同观测要求两期SCL均属于4/5/6且指数有效有限。编码：0=稳定非水体、1=持续水体、2=新增水体候选、3=退水、4=无效观测；研究区外NoData=255。原始分类保留全部候选，最小图斑阈值只筛选矢量与保留面积，原始／保留／筛除面积分别保存。

面积按四邻接多边形的WGS84椭球面积计算，研究区采用像元中心纳入，几何面积与栅格化面积分开保存。四个输入须具有完全一致的CRS、原点、范围和分辨率，不静默对齐。单次至多四百万输入像元、五万个分类片段、一万个保留候选，超限明确失败。

| 文件 | 内容 |
| --- | --- |
| result.tif | 原始变化分类及显式图例 |
| added-water.geojson | 保留候选、面积、观测日期和研判身份 |
| metrics.json / metrics.csv | 指标、单位、质量覆盖和统计口径 |
| assessment.json | 研究区、方法及完整输入快照，包含来源OGE任务／脚本引用、文件大小与SHA-256校验值 |
| brief.md / brief.pdf | 固定简报，数字由程序生成，包含质量与适用限制 |

持续水体不称永久水体，新增候选不称已核实淹没，退水期观测不代表洪峰最大范围。SCL不是独立精度真值，缺少承灾对象数据时不报告受灾人口及损失。

分类瓦片用离散色和最近邻。`KUNYU_RGB_RANGES`可声明三个显示范围，`KUNYU_DISPLAY_RANGE`声明一个范围，均为JSON数值对列表，仅控制显示。贵港两期RGB使用相同0..3000 COG数值范围，保留源像元。

## 数据准备与升级

`scripts/prepare_oge_assets.py`使用明确资产清单分别执行download/crop/upload，不自动覆盖或重发上传，不包含批量删除。清单为OGE资产记录JSON数组，原图位于指定目录`originals/`，裁剪写入`cropped/`及`crop-manifest.json`。上传要求清单完整并保存每次回执，已有回执时先核对平台状态。

```bash
uv run --project backend python scripts/prepare_oge_assets.py crop \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --aoi "/准备目录/study-area.geojson" --suffix yujiang_v1

uv run --project backend python scripts/prepare_oge_assets.py upload \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --data-directory "/业务目录"
```

账号认证须在OGE完成，重新登录不授予上传资格。新资产上传后还须核对范围、波段和真实算子读取／计算，全部可用再逐一删除对应旧UUID，历史快照不改写。本次材料位于下载目录`kunyu-guigang-20261021`，业务副本位于“贵港洪涝研判”的`files/guigang/`。

数据库统一版本13，新增`study_areas`和`assessments`。版本12使用`upgrade_assessment_storage.py`显式升级，先生成权限600的备份，再事务建表；其他版本拒绝。本机已完成升级并实际恢复Electron及后端启动。

界面复用Tailwind／shadcn及Mu风格；结果沿用harness对身份、拥有者、终态和不重放的约定。不新增或修改仓库测试。
