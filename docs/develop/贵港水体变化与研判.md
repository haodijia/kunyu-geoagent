## 数据准备与升级

`scripts/prepare_oge_assets.py`使用明确资产清单分别执行download/crop/upload，不自动覆盖或重发上传，不包含批量删除。清单为OGE资产记录JSON数组，原图位于指定目录`originals/`，裁剪写入`cropped/`及`crop-manifest.json`。上传要求清单完整并保存每次回执，已有回执时先核对平台状态。

```bash
uv run --project backend python scripts/prepare_oge_assets.py crop \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --aoi "/准备目录/study-area.geojson" --suffix yujiang_v1

uv run --project backend python scripts/prepare_oge_assets.py upload \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --data-directory "/业务目录"
```

账号认证已完成。上传表单的整数分辨率按`10`/`20`发送。六份新资产已回下载并核验，当前被读取算子阻断，未删除旧资产，也未将本地计算替代远端结果。本次材料位于下载目录`kunyu-guigang-20261021`，新旧UUID及文件名见其中`资产引用.md`，上传及字节核验见`replacement-assets-certified.json`，编译失败见`remote-read-jobs.json`，定义接口核查见`loader-definition-check.json`。业务副本位于“贵港洪涝研判”的`files/guigang/`。

继续时先读取实时算子定义；只有平台恢复`Service.getCoverageFromUpload`后，才重新编译读取校验代码，执行导出并比对真实像元。此前失败发生在编译阶段，没有生成已提交任务。不要重传已登记的新资产或绕过平台定义拼造DAG。六份全部通过后逐一核对并删除对应旧UUID，历史快照保留。
