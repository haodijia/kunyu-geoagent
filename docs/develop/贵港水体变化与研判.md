## 数据准备与升级

`scripts/prepare_oge_assets.py`使用明确资产清单分别执行download/crop/upload，不自动覆盖或重发上传，不包含批量删除。清单为OGE资产记录JSON数组，原图位于指定目录`originals/`，裁剪写入`cropped/`及`crop-manifest.json`。上传要求清单完整并保存每次回执，已有回执时先核对平台状态。

```bash
uv run --project backend python scripts/prepare_oge_assets.py crop \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --aoi "/准备目录/study-area.geojson" --suffix yujiang_v1

uv run --project backend python scripts/prepare_oge_assets.py upload \
  --manifest "/准备目录/source-assets.json" --directory "/准备目录" \
  --data-directory "/业务目录"
```

账号认证已完成。上传表单的整数分辨率按`10`/`20`发送。六份新资产已通过回下载字节核验及真实远端计算，旧六份已删除，本地原始归档保留。本次材料位于下载目录`kunyu-guigang-20261021`，新旧UUID及文件名见其中`资产引用.md`，上传及字节核验见`replacement-assets-certified.json`，远端任务及全像元核验见`native-mydata-read-jobs.json`，旧资产删除回执见`old-assets-deletion.json`。业务副本位于“贵港洪涝研判”的`files/guigang/`。

`Service.getCoverageFromUpload`不可用不代表个人数据无法计算。已验证原生算子入口支持官网工具箱的`Personal:MyData`文件名引用；本次`Personal:Asset:{UUID}`请求受理后因缺少productName失败，不能将两种引用等同。具体调用及边界见[OGE原生算子调用核验](OGE原生算子调用核验.md)。本次不改既有`oge_execute_code`接口；其SDK单DAG读取个人资产尚未验证成功，原生接口核验不代表该SDK链路已经打通。
