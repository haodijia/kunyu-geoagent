# 结果展示与地图交互

## 主链路

用户提问 → Agent 使用原有 OGE 工具查询与执行 → 自动下载至 results 并登记 → Agent 读取预览／元数据 → map_present 上图 → 按需调整显隐、透明度、顺序 → 用户在地图继续提问。

oge_execute_code 的参数、远端协议、单 Coverage 导出与后台任务生命周期保持原样，不增加业务含义或分类字段。像元含义由 Agent 依据实际代码解释，前端仅使用栅格本身已有的信息，不从 0/1 推断类别。

## 结果卡

工具调用结果与工作区列表共用 OutputCard。提供预览大图、原始下载、查看地图、继续提问；元数据及来源代码收在详情中。显式 TIFF 分类标签可显示图例，否则单波段显示数值色带。

历史成果沿用 /workspace/results/... 文件引用。result_get_info(file_path) 只读本工作区已登记成果，返回真实 ID、元数据和代码来源；后续 map_present、取值与统计使用返回的 ID。没有改变已有文件引用格式。

## 地图交互

点击图层只选择操作对象，不展开预览与操作区；继续提问使用图层行内按钮。像元查询、圈选范围和卷帘对比统一放在右侧地图工具栏，三个按钮在所有会话都可打开，操作面板与查询结果排列在左侧图层列表下方。图标分别使用图钉、虚线矩形和分隔对比。启用像元查询后鼠标变为十字光标，点击地图在左侧显示源数值，不从显示颜色读数。没有本地栅格时明确提示，不用预览图片代替取值。范围选择默认进入矩形绘制，也支持多边形及 GeoJSON 导入，无图层也可圈选。

卷帘通过地图分隔线和把手直接拖动，拖动只调整分界位置；也支持方向键和 Home／End。用户可在任意会话直接打开卷帘面板，选择两个有空间范围的图层（包括隐藏图层）；不足两个时显示添加图层提示。Agent 使用同一功能 map_compare(layer_ids=[左层ID, 右层ID]) 请求开启卷帘，传 null 结束。前端按需加载参与比较的隐藏图层，不改变保存的显隐或透明度。切换地图工具、关闭操作面板或按 Esc 会退出当前操作。

圈选完成后直接写入当前会话地图状态；点位可点击“带入对话”写入同一状态。输入框左下角定位名称后显示“已圈选”或“已选点”，点击该状态可清除，不另占一行。用户发送问题（含排队、追问和会话命令）时，map_context.selection 携带 WGS84 geometry 与可选 layer_id，保存为该问题的不可变快照。构建模型历史时将该快照附在对应用户问题前，不写入 files、不上传 GeoJSON，也不修改用户输入的正文。关闭面板或切换工具保留已完成的范围与地图轮廓；清除选择后后续问题不再附带范围。排队消息恢复编辑时同时恢复其选择快照。Agent 直接使用几何数据，按 layer_id 查询成果来源后统计或执行 OGE，不自动发送消息或执行计算。

本地区域统计仅核对既有单波段成果，最多四百万像元。分类名称仅使用文件已有映射；Agent 可依据实际代码显式指定最多32个数字值测量其像元数量与面积，返回值本身，不自动把1解释为水体。新算法与数据处理继续通过 OGE 完成。

## 展示反馈

map_present 成功代表图层已添加。地图客户端报告当前层 ID、revision、loading/ready/failed/hidden，map_get_context 返回 rendering；未连接或超过三十秒没有报告为 unavailable。只有当前层版本均获确认才返回 ready。状态在内存，关闭后清除，不写入历史图层记录；地图截图仍遵守现有模型图片能力设置。

## 存储与清理

已移除独立研判面板、固定四输入分析／报告服务和 assessment_create、study_area_get/set。通用取值与区域统计保留。版本 14 统一 SQL 有 25 张表；升级脚本先备份再删除退役存储，保留对话、任务、成果、图层及工作区文件。

未新增或修改仓库测试。OGE 认证已完成，六份裁剪新资产已通过接口上传、原生算子实算和全像元核验，旧六份已删除。该数据验收未修改既有代码工具；个人资产的SDK单DAG读取仍须另行核验，详见[贵港水体变化与研判](贵港水体变化与研判.md)。
