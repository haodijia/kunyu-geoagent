# 结果展示与地图交互

## 主链路

用户提问 → Agent 使用原有 OGE 工具查询与执行 → 自动下载至 results 并登记 → Agent 读取预览／元数据 → map_present 上图 → 按需调整显隐、透明度、顺序 → 用户在地图继续提问。

已发布服务使用 oge_get_service_definition / oge_execute_service，自定义算子链使用 oge_execute_code。后者可声明 products；一次仍只导出一个 Coverage。完整数值包按显式波段契约派生多个成果，统一任务、来源与方法版本。前端使用声明的类别与图例，不从0/1推断业务含义。

## 结果卡

工具调用结果与工作区列表共用 OutputCard。提供预览大图、原始下载、查看地图、继续提问；元数据及来源代码收在详情中。显式 TIFF 分类标签可显示图例，否则单波段显示数值色带。完整成果按契约的group组织主题切换，显示各产品的数值或分类统计。工作区按完整成果分组，不把21个波段展开成21张卡。单产品与完整数值包都可下载。

历史成果沿用 /workspace/results/... 文件引用。result_get_info(file_path) 只读本工作区已登记成果，返回真实 ID、元数据和代码来源；后续 map_present、取值与统计使用返回的 ID。没有改变已有文件引用格式。

## 地图交互

点击图层选择查询对象，并展开紧凑的透明度、引用和图例。默认直接点击地图读取源像元值；没有本地数值成果时提示选择成果，不用预览颜色代替数值。圈选工具按下、拖动、松开即完成矩形并自动统计，也支持逐点多边形（双击完成）与GeoJSON导入，无图层也能圈选。操作提示在地图上方，结果在与图层列表共享布局的侧栏，不在操作前弹窗。点查或圈选后直接输入问题即可，不需要确认或再次点“带入对话”。本组成果选择器复用已有产品，切换后更新查询对象，不重新提交OGE。

卷帘通过地图分隔线和把手直接拖动，拖动只调整分界位置；也支持方向键和 Home／End。有两个可见图层时点击卷帘立即开始；也可在紧凑控制区更换两个有空间范围的图层（包括隐藏图层）；不足两个时显示添加图层提示。Agent 使用同一功能 map_compare(layer_ids=[左层ID, 右层ID]) 请求开启卷帘，传 null 结束。前端按需加载参与比较的隐藏图层，不改变保存的显隐或透明度。切换地图工具、关闭操作面板或按 Esc 会退出当前操作。

圈选与点查都直接写入当前会话地图状态。输入框左下角定位名称后显示“已圈选”或“已选点”，点击该状态可清除，不另占一行。用户发送问题（含排队、追问和会话命令）时，map_context.selection 携带 WGS84 geometry 与可选 layer_id，保存为该问题的不可变快照。构建模型历史时将该快照附在对应用户问题前，不写入 files、不上传 GeoJSON，也不修改用户输入的正文。切换工具保留已完成的范围与地图轮廓；Esc或清除选择移除选区，后续问题不再附带范围。排队消息恢复编辑时同时恢复其选择快照。Agent 直接使用几何数据，按 layer_id 查询成果来源后统计或执行 OGE，不自动发送消息或执行计算。

本地区域统计仅核对既有单波段成果，最多四百万像元。分类名称仅使用文件已有映射；Agent 可依据实际代码显式指定最多32个数字值测量其像元数量与面积，返回值本身，不自动把1解释为水体。新算法与数据处理继续通过 OGE 完成。

## 展示反馈

map_present 成功代表图层已添加。地图客户端报告当前层 ID、revision、loading/ready/failed/hidden，map_get_context 返回 rendering；未连接或超过三十秒没有报告为 unavailable。只有当前层版本均获确认才返回 ready。状态在内存，关闭后清除，不写入历史图层记录；地图截图仍遵守现有模型图片能力设置。
