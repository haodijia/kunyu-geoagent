# 地图服务

地图采用 MapLibre GL JS 单引擎，二维为平面地图，三维启用真实 DEM 地形和山体阴影；三维默认俯仰角 55°、地形夸张系数 1。当前默认定位榕江县，复杂三维模型和 OGE 业务图层尚未接入。

## 数据服务

| 数据 | 当前服务 | 用途 |
| --- | --- | --- |
| 浅色矢量底图 | OpenFreeMap Liberty | 道路、地名、水系等背景 |
| 深色矢量底图 | OpenFreeMap Fiord | 跟随应用解析后的深色主题 |
| 高程 | Mapterhorn TileJSON | Terrarium 编码，512 像素 DEM 瓦片 |

地址集中在 `frontend/src/features/maps/runtime/config.ts`，使用公开 HTTPS 服务，无需 API key；所有瓦片、字体和图标仍需联网。替换为自建或其他授权服务时，应同时确认样式引用的瓦片、字体、图标地址、DEM 编码和来源署名。当前 DEM 最大源级别设为 12，高级别采用该级别高程，不代表现场测量精度。

官方说明：[OpenFreeMap](https://openfreemap.org/quick_start/)、[Mapterhorn](https://mapterhorn.com/data-access/)、[MapLibre 地形](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)。

## 代码职责

- `features/maps/runtime/config.ts`：服务与地形参数。
- `features/maps/runtime/useSessionMap.ts`：实例生命周期、维度切换、主题切换、状态同步及资源错误。
- `features/maps/MapToolbar.tsx`：复用 Button、Tooltip 的地图工具栏。
- `features/maps/map.css`：地图容器、来源署名及比例尺的局部样式。
- `features/sessions/views/MapView.tsx`：地图、加载／失败提示和已有会话输入框的组合。
- `features/sessions/map-context.ts` 与 `app/store.ts`：会话视口及相机状态。

## 状态与交互

二维／三维切换复用同一地图实例。二维限制俯仰角为 0；三维启用 DEM、山体阴影并允许右键拖动旋转和倾斜。切回二维时删除地形和阴影图层及其数据源。

切换主题重新加载底图样式并恢复当前维度。离开地图页时保存经纬度、缩放、方位角、俯仰角和维度，释放地图实例、观察器和计时器；返回同一会话恢复这些状态。状态保存在 Zustand 内存中，刷新窗口或重启应用后重新初始化。

`camera` 为前端展示状态，不进入现有 Agent 地图快照；消息接口继续传递经纬度和缩放等原有字段。恢复排队消息时按其地图快照恢复视口，相机初始化为二维。

比例尺与来源署名随底部输入框实际高度移动，地图中心也避开输入框区域。资源加载、初始化、WebGL 上下文丢失及首次加载超时会记录错误并显示可手动重新加载的提示，不自动换用其他地图源。

MapLibre Worker 由 Vite 单独构建，本地加载；Worker 与其他构建文件一样使用固定文件名，不添加 hash。
