# 工作区总览

更新：2026-10-25。路由 `/workspaces/:workspaceId/overview`。

## 页面与交互

总览固定在视口内，采用两列两行：文件空间、成果画廊、Agent 活动、记忆与规范。页面本身不滚动；文件列表、长规范和预览内容在自身区域内滚动。沿用 Mu 的轻量面板、柔和边框与紧凑文件行，复用现有 Button、Textarea、AlertDialog、OutputCard 和文件预览组件；Agent 指标以 harness 风格的持久化运行计数为依据。

- 文件空间直接浏览 `/workspace` 下的 attachments、files、results，点击文件打开预览。成果文件的关联按钮选中对应画廊成果，画廊的定位按钮打开目录并将对应文件滚动到可见位置。
- 成果画廊以三张错位卡片展示当前与相邻成果，支持两侧卡片、箭头、圆点和聚焦后的左右方向键。一个 bundle 是一项成果；查看成果后复用原有产品分组、图例、统计、地图和下载入口。没有自动轮播计时器。
- 删除入口同时出现在画廊和关联文件行。删除确认明确说明永久删除的范围；选择 bundle 子产品时，删除整个所属成果组，包括数值文件、原始成果包、预览和所有会话中的关联地图图层。源影像和会话记录保留。
- Agent 活动显示累计运行、工具调用、供应商 Token 用量、近七个 UTC 日期的运行数量及累计状态。缺少 Token 上报时显示 `—`，并提供已上报运行数，不生成演示指标。
- 工作记忆可新增、查看和编辑，显示最近 100 条及总数量。工作区规范直接查看和编辑根目录 `AGENTS.md`。编辑在卡片内完成，取消不保存；失败保留草稿并显示错误。规范是否注入 Agent 仍由既有项目规范设置决定。

## 接口与数据边界

所有路径以 `/api/v1/workspaces/{workspace_id}` 为前缀，沿用现有身份验证；服务层检查工作区仍有效。

| 方法与路径 | 用途 |
| --- | --- |
| GET `/overview` | 持久化运行聚合、七日活动、最近记忆及总数 |
| POST `/memories` | 新增用户记忆，最多 2000 字符 |
| PATCH `/memories/{memory_id}` | 以 `expected_content` 检查原内容后保存 |
| GET `/instructions` | 返回 UTF-8 内容和文件版本；不存在时版本为 null |
| PUT `/instructions` | 以原 `version` 保存，UTF-8 上限 128 KiB |
| DELETE `/results/{output_id}` | 删除所属成果组并返回成果 ID、受影响会话 ID |

手动记忆使用明确的 `workspace_editor:` 来源标记。规范保存有专用单文件入口，只允许 `/workspace/AGENTS.md`；不放宽 Agent 文件工具原有的写入范围。原内容或版本已变化返回 409，跨工作区对象返回 404，规范超出字节限制返回 413。

成果删除只处理数据库登记的成果目录和缓存目录文件，拒绝越界、符号链接、缺失文件及其他成果共享的文件。先在同一文件系统暂存，再事务性移除成果与地图记录；捕获到事务失败时恢复暂存文件。仅清理空目录，保留未登记的其他文件。此流程不承诺操作系统崩溃时的跨文件系统／数据库原子性。前端随后刷新文件、成果与受影响地图缓存。无需数据库迁移或新增依赖。
