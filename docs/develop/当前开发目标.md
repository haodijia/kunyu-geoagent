# 当前开发目标

用户在 2026-10-10 选择第 1、2、6、12 项。完成本阶段后进入坤舆业务开发，停止无限扩展通用 Agent 能力。

## 本阶段范围与验收

1. 对话 UI 收尾：以 Mu 为参考，核查消息、输入框、思考区、工具卡、审批与空状态；浅色、深色、窄屏无溢出，状态与实际运行一致。
2. 工具与轨迹展示收尾：以 deepseek-harness 为参考，统一运行、等待、失败、取消；参数、结果、耗时和来源可核对，详情与日志一致。
3. 多 Agent 委派：主 Agent 可分派子任务；子任务拥有独立上下文、受限权限与模型快照；支持查看、等待、取消和结果汇总，生命周期进入持久日志。父任务停止和应用关闭清理子任务，重启不重复执行外部副作用。
4. 开发收尾：更新架构及范围文档、清理过时代码和依赖、整理开发阶段数据库为统一 SQL；完成构建、静态检查和真实应用流程验证，不新增仓库测试。真实付费模型及业务服务验证以实际可用凭据为前提，不能用模拟结果冒充。

## 不属于本阶段

草稿重启持久化、项目自身的 /goal、程序化工具调用 PTC、远程 Skill 与脚本执行、额外压缩策略、Agent 配置模板、MCP 高级能力及插件市场不在本阶段实施。

对话分支、通用文件工作台、右侧文件预览、Office／完整 PDF 控件、文件管理、通用终端继续排除。多 Agent 的子任务关系不提供用户会话 fork 功能。

## 下一阶段

四项验收完成后，转入坤舆实际地理业务接口、任务和地图结果流程。具体业务范围以用户后续选择为准。
