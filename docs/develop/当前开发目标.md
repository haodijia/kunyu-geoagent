# 当前开发目标

通用 Agent 基础阶段已完成，历史验收见[本阶段验收](本阶段验收.md)。当前实施用户确定的四项业务能力：真实洪涝案例、地图分析核查、成果业务表达和可复核报告。

## 当前案例

先使用已有贵港 Sentinel-2A L2A，2026-06-22 为灾前背景、2026-07-12 为灾后／退水期，图幅49QCF。业务区域由显式研究区管理，后续榕江数据复用同一实现。

数据准备、接口、工具、核查证据及实际限制统一维护于[贵港水体变化与研判](贵港水体变化与研判.md)。

## 验收边界

- 完成研究区、源像元、区域统计、卷帘、分类表达、候选矢量及固定简报的软件实现和真实像元检查。
- 新资产须上传并完成真实读取／计算验证后，才能替换、删除旧资产。
- 平台拒绝权限时保留原资产和本地准备材料，不把软件验收样例冒充 OGE 完整案例。
- 独立样本校准、精度评价、承灾对象叠加与最终案例实算按实际数据及权限继续，未完成项在报告中明确。
- 不新增或修改仓库测试；完成构建、静态检查、实际应用核查与数据库升级验证，完成开发后自动提交。

## 不属于本阶段

草稿重启持久化、项目自身的 /goal、程序化工具调用 PTC、远程 Skill 与脚本执行、额外压缩策略、Agent 配置模板、MCP 高级能力及插件市场不在本阶段实施。

对话分支、通用文件工作台、右侧文件预览、Office／完整 PDF 控件、文件管理、通用终端继续排除。多 Agent 的子任务关系不提供用户会话 fork 功能。
