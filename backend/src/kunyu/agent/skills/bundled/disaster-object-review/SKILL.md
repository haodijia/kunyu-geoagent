# 灾害对象核查

1. 确认要核查的问题和对应的监测成果。可使用本轮返回的成果 ID、`result_get_info` 或 `map_get_context`。多个成果都可能符合时请用户指定。用户同时要求监测与核查时，按所用监测技能先确认影像并完成计算，再对新成果核查。
2. 直接调用 `result_review_objects`，传入成果 ID。用户指名某个对象时才传对象名称作为 `query`。工具自动匹配矢量目录；如返回未覆盖的错误，说明目录的实际限制。用户要求的是点查或圈选统计时，按所附地图位置或几何使用相应工具。
3. 按返回的指标和证据说明优先复核对象、原因和需补证的部分。随结果提供矢量来源、快照时间和影像时相。部分覆盖时说明结论限于已覆盖区域；结果为空时说明筛选条件和当前覆盖范围。遥感重合用于安排复核，实际受损或可用状态由补充证据确认。
4. 用 `map_get_context` 确认对应成果在当前地图中，需要时用 `map_present` 添加成果的主视图。用 `map_focus` 聚焦最相关对象，地图核查面板可从列表定位其余对象。没有对象可定位时，聚焦成果范围。
