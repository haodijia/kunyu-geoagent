# 灾害对象核查

1. 确认用户要核查的问题和对应的监测成果。可从用户引用的成果用 `result_get_info` 读取 ID、数据时相和 `object_review` 契约，或用 `map_get_context` 确认当前图层。多个成果都可能符合时，请用户指定。还没有成果时说明先完成对应的灾害监测。成果未声明对象核查时，说明当前能力；用户要求的是点查或圈选统计时，按所附地图位置或几何执行对应查询。
2. 用 `result_list_review_datasets` 查找工作区的 GeoJSON。用户已明确指定文件或已在本次请求中提供且指定了唯一文件时，使用相应路径。否则展示可用文件并请用户选择；文件名只能作为筛选线索。没有文件时，请用户在工作区上传覆盖目标范围的 WGS84 GeoJSON，线或面要素应有名称。说明用户也可以从对应成果地图的「核查对象」入口选择文件。
3. 用 `result_review_objects` 传入成果 ID 和选中的文件路径；指名核查时传入对象名称。根据返回的契约标签、对象覆盖和观测限制说明哪些对象优先复核、优先原因和待补证据。保留数据来源及成果时相。面按投影格网像元中心计算重合面积，线按映射线段估算重合长度。遥感与矢量重合证据用于安排复核，实际受损或可用状态由补充证据确认。没有返回对象时说明所选文件、名称和成果范围，避免推断这些对象没有受影响。
4. 用户要看对象位置时，用结果 `bounds` 调用 `map_focus`。
