# 双时相光学水体变化核查

## 数据准入

- 记录每份输入的资产 UUID、文件名、产品身份、观测时间、空间范围和实际波段。个人资产的 filePath/cogPath 不是下载 URL。
- 检查波段描述与来源元数据。多波段 GeoTIFF 的第几个波段不能凭产品名称推断；OGE 导入后的实际波段身份也需核实。
- 保存辐射转换依据。Sentinel-2 原始 SAFE 的 BOA_ADD_OFFSET 不必然适用于派生 COG；Earth Search 的全局 boa_offset_applied 和逐资产 scale/offset 可能不一致。发现矛盾时停止指数计算，使用同产品 JP2/COG 像元比对确认解释，并保存证据。不得重复减偏移。
- MNDWI=(Green-SWIR1)/(Green+SWIR1)，NDWI=(Green-NIR)/(Green+NIR)。转换为浮点，分母为零、原始无数据与非有限值必须无效化。
- 涉及原生 20 米 SWIR 的主成果使用 20 米分析网格。统一 CRS、原点、范围和像元大小；连续反射率按明确方法汇总，SCL／分类采用最近邻。

## 质量、阈值与变化

- 当前固定质量规则是两期 SCL 均属于 4、5、6，同时指数有效。未分类、阴影、云、雪和无数据均不纳入共同有效观测。
- 不将 SCL 水体类别当作独立分类精度真值。阈值记录校准样本和依据；阈值0可以作为明确声明的探索参数，不能声称为普适或验证成功的洪涝阈值。
- 共同有效区域内区分稳定非水体、持续水体、新增水体候选、退水；无效观测单列，研究区外为 NoData。
- 原始分类保留全部候选。最小图斑以平方米配置，只筛选输出矢量及“保留候选”指标，同时保留原始候选面积和筛除面积。
- 面积使用 WGS84 椭球测量，记录像元中心纳入规则、共同有效面积和分母。不得用地图 Web Mercator 显示面积替代统计。

## 地图与报告

- 卷帘对比用于目视核查；像元与区域统计来自源 GeoTIFF。颜色、透明度与截图不能代替数值证据。
- 变化计算在 OGE 执行。结果通过 map_present 展示，关键数字须来自实际计算或统计；OGE 代码、任务与成果沿用现有任务记录。
- 记录观测日期与灾害时间关系。灾后／退水期结果仅反映过境时刻；永久水体、最大淹没范围、受灾人口和损失需要额外证据。
- 若上传或计算权限被平台拒绝，保存实际错误并停止对应操作。裁剪文件可继续本地核验；不得伪造平台成功，也不得删除尚未成功替换的原资产。
