# OGE 洪涝遥感研判

“分析贵港郁江 2026 年 6 月 22 日和 7 月 12 日的水体变化”“比较 2022 年 5 月和 6 月英德大站镇附近的水体变化”都足以开始选景。从用户原话提取区域、时段和目标。给出月份时在对应月份内选景，在提案中列出实际采集日期。已有成果的解释、切换视图、点查和局部统计可直接复用成果。需要核实案例数据或参数时，从技能资源目录读取 [服务指南](references/service-guide.md) 和 [案例资料](references/cases.md)。

## 影像和服务的选择

案例区域先用已知检索词调用 `oge_list_my_data`，以返回的资产名称、后缀和日期核实配套数据。只有清单和案例资料缺少必要信息时再查询相应的 `oge_get_my_data_detail`。其他区域可用 `oge_find_regions` 和 `oge_search_images` 检索候选，按照范围、采集日期、波段和云影筛选。公开目录条目只有备齐服务要求的个人数据资产后才能用于本服务。

`oge_get_service_definition` 提供 `flood_monitoring_bundle` 的版本、参数及成果契约。计算读取范围由资产的预对齐网格决定。地图选区、日期和行政区用于发现数据或查询既有成果，不能作为该服务的计算参数。区域或时间改变时确认六份影像及对应关注点栅格，避免沿用其他案例的默认输入。缺少兼容的前后期观测时说明缺口，或请用户确认有依据的可选时相。实际日期和有效覆盖随结论呈现。

## 展示影像并等待确认

数据齐备后，先发一条用户可见的简短消息，按前期、后期列出实际日期、传感器、分辨率和覆盖范围，说明为什么选这两期。有依据时补充云影或覆盖缺口。最后询问“可以用这两期影像计算吗？”，并在同一个步骤调用 `oge_execute_service`，使用其审批卡等待决定。审批卡展示服务将读取的文件，用户同意后系统才会提交作业。这一步使用服务自身的审批。不要另外调用 `ask_user_question` 再确认一次。用户拒绝或取消时等待后续指示。

在服务参数里显式传入已核实的前后期六份资产、关注点栅格及其 ID 上限。这样审批对应本次选景，避免将案例默认文件当作检索结果。阈值对比固定影像、关注点和统计范围，保留原成果，并记录改变的阈值和新成果引用。

## 跟踪和上图

`oge_execute_service` 返回进行中的应用任务时，用 `job_output` 等待或查询同一个 `job.id`。超时后可继续查询；未知任务 ID 时先用 `job_list`，提交状态不明时确认已有回执。应用任务 ID 与远端 `jobId` 分开记录。遇到鉴权、参数、输入或执行错误时报告实际错误及对应修正条件。

成果可用后，用实际的 `analysis_output_id` 和声明的视图调用 `map_present`，把主视图 `change_class` 加到当前会话地图，显式传入 `open_map: false, focus: false`。随后用返回的 `layers[0].id` 调用 `map_focus`，打开地图并将视角定位至主图层。用户要看局部时，可用 `map_focus` 的 `bounds` 给出已核实的范围。质量、指数和前后期水体等辅助视图按问题添加；只有用户明确要求目视对照时才开启卷帘。需要确认渲染时用 `map_get_context` 传入 `{"include_screenshot":false}`。未收到客户端反馈时，以工具回执说明图层和定位请求。

对“这里”“这片”使用消息附带的 `map_selection` 或地图上下文。将 `layer_id` 对应到 `output_id`、`view_id`，用 `map_sample_raster` 点查，用 `map_region_statistics` 统计同一几何。面积报告说明统计区域、共同有效覆盖和口径。全幅面积直接读取波段 summary 的类别计数与投影网格像元面积。选区统计按像元中心与 WGS84 椭球面积。需要定位核查候选时可先看成果预览或地图，再对与问题有关的河段点查或圈选；只有指定选区超过统计限制时才按业务范围分区。

## 研判证据

分类含 0 稳定非水体、1 持续水体、2 新增水体候选、3 退水、4 指数分歧、5 无共同有效观测。0 虽透明仍计入相应统计；5 有明确含义，研究区外为 NoData。敏感性票数是九组阈值组合中的计数，九组一致只说明在指定扰动范围内稳定。点位需由实际 `poi_id` 与来源关联。

定位后用简短结论带用户读主图层。依据实际结果说明持续水体、新增候选和退水的面积及统计范围，指出无共同有效观测或指数分歧带来的缺口。描述变化集中位置时使用真实预览、点查或圈选统计作为依据。两期独立的水体总量与双期共同有效范围内的增减使用不同口径，分别说明。洪峰范围、水深、人口和损失需要独立资料。用户只问局部或解释时，聚焦该问题的证据。
