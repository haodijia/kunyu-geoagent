## 为什么选择坤舆智枢

灾害研判往往需要在有限时间内完成遥感数据检索、空间分析与结果解读，传统流程涉及多种工具和较高的专业门槛。坤舆智枢以场景化智能体组织研判过程，将自然语言交互与 OGE 地理空间能力结合，帮助用户围绕具体灾害事件快速形成清晰、可追溯的分析思路。

项目面向遥感、地理信息与应急管理等领域，希望让专业分析能力更容易被调用，也让复杂的地理空间研判流程更便于理解与协作。

## 应用场景

- 洪涝、森林火灾、地震与地质灾害等事件的遥感研判
- 灾前背景分析、灾中动态监测与灾后影响评估
- 应急制图、空间信息查询与辅助决策
- 遥感与地理信息教学、演示及科研实验
